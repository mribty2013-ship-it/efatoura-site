Installation

  1. Téléchargez eFatoura-Setup-1.1.0.exe et ouvrez-le.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même.
  3. Suivez l'assistant : eFatoura s'installe et crée un raccourci sur le bureau.
  4. Connectez-vous avec le compte créé par votre cabinet, ou demandez une démo pour en obtenir un.

Désinstallation : Paramètres Windows › Applications › eFatoura. Vos données restent conservées sur la plateforme.
